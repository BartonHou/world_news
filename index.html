How it works

Every week, an automated pipeline pulls fresh signals for 20 countries and asks an LLM to turn them into short, outsider-friendly cards.

  • News — top stories from Google News, summarized.
  • Internet culture — real posts from each country's Reddit communities and its trending YouTube videos, balanced so you get both discussion and what people are watching.
  • Everything is pre-generated — the map only reads static JSON, so browsing never calls an API.

Summaries are AI-generated and can be incomplete or imperfect — always check the original source. Built by Jingyuan Hou. Source on GitHub.
